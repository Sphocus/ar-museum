1. Choose a gallery

Width goes left to right and depth goes ahead of you, as you face the way the gallery opens. The room outline shows on the floor once you set the start spot, and models outside it are flagged.

How it works
  1. Stand on the start spot and aim at the floor about 2 m ahead, the way the gallery should open. Tap.
  2. Tap Add model, choose one, aim at the floor (or a table) and tap to put it there.
  3. Tap a model to select it. Use Size, Turn and Height, or Move, Copy, Delete.
  4. Tap Lock & save, then save the gallery below.
2. Save to GitHub

How to make the token (once)
  1. On GitHub: your profile photo, Settings, Developer settings, Personal access tokens, Fine-grained tokens, Generate new token.
  2. Name it, choose an expiry, and under Repository access pick Only select repositories and choose your museum repository.
  3. Under Permissions, Repository permissions, set Contents to Read and write. Generate it and paste it above.
  4. Only you can save while the token stays private. Delete it in GitHub any time to switch saving off.
3. Models

All models: hide or make public
Add a new model

Pick the finished .glb file. It is uploaded to the models folder and added as unlisted, so it shows in the camera list but not in the public gallery. Set its default size and direction in the camera (Make default), then tap Make public here when it is ready. Uses the token from step 2.
